## 🟢 Problem 1 — Count Odd Numbers

Write a function `countOdd(numbers)` that returns the number of **odd numbers** in an array.

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not an array.
- ❌ Any element is not a finite number.

---

## 🟢 Problem 2 — Find the Second Largest Number

Write a function `findSecondLargest(numbers)` that returns the **second largest unique number**.

### 📝 Example

```javascript
findSecondLargest([10, 20, 5, 20, 15]);
```

### ✅ Output

```text
15
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not an array.
- ❌ Array has fewer than 2 unique numbers.
- ❌ Any element is invalid.

---

## 🟡 Problem 3 — Count Character

Write a function `countCharacter(text, character)` that counts how many times a character appears in a string.

### 📝 Example

```javascript
countCharacter("JavaScript", "a");
```

### ✅ Output

```text
2
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input types are invalid.
- ❌ Character length is not exactly 1.

## 🟡 Problem 4 — Remove Duplicates

Write a function `removeDuplicates(numbers)` that returns a new array without duplicate values.

### 📝 Example

```javascript
removeDuplicates([1, 2, 2, 3, 4, 4, 5]);
```

### ✅ Output

```javascript
[1, 2, 3, 4, 5]
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not an array.
- ❌ Any element is not a finite number.
