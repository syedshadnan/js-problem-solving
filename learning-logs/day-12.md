## Key Learnings

- reduce() is used to transform an array into a single value.
- The accumulator stores the running result during each iteration.
- Initial value helps prevent errors when working with empty arrays.
- reduce() can be used to calculate totals, averages, and reports.
- Multiple array values can be aggregated into a single output.
- reduce() can work with both primitive values and objects.
- Business rules should be validated before performing calculations.

## Common Mistakes

- Confused accumulator with initial value.
- Incorrect multiplication result during reduce() dry run.
- Forgot to handle empty array case in averageMarks().
- Initially focused only on calculation without considering edge cases.
