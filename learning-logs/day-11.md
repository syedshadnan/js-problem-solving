## Key Learnings

- find() returns the first matching element.
- findIndex() returns the index of the first matching element.
- some() returns true if at least one element satisfies a condition.
- every() returns true if all elements satisfy a condition.
- Learned the difference between some() and every().
- Learned that find() returns undefined when no match is found.
- Learned that findIndex() returns -1 when no match is found.
- Practiced validating arrays of objects.
- Improved input validation using some() and every().
