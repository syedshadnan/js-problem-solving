## 🟢 Problem 1 — Even or Odd

Write a function `isEven(number)` that checks whether a number is even or odd.

### 📝 Requirements

- ✅ Return `true` if the number is even.
- ✅ Return `false` if the number is odd.
- ❌ Return `"Invalid"` if the input is not a valid number.

---

## 🟢 Problem 2 — Count Vowels

Write a function `countVowels(str)` that counts the total number of vowels in a string.

### 📝 Requirements

- ✅ Count all vowels (`a`, `e`, `i`, `o`, `u`).
- ✅ Support both uppercase and lowercase letters.
- ❌ Return `"Invalid"` if the input is not a string.

---

## 🟢 Problem 3 — Find the Largest Number

Write a function `findLargest(numbers)` that returns the largest number from an array.

### 📝 Requirements

- ✅ Input must be an array.
- ✅ Return the largest number.
- ❌ Return `"Invalid"` if:
  - Input is not an array.
  - Array is empty.

---

## 🟢 Problem 4 — Reverse String

Write a function `reverseText(text)` that returns the reversed version of a string.

### 📝 Example

```javascript
reverseText("hello");
```

### ✅ Output

```text
olleh
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not a string.

---

## 🟢 Problem 5 — Multiplication Table

Write a function `multiplicationTable(number)` that returns the multiplication table of a number from **1 to 10**.

### 📝 Example

```javascript
multiplicationTable(5);
```

### ✅ Output

```javascript
[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not a valid number.
