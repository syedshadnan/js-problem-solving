===========================
JavaScript Problem Solving
Day 01
===========================

Problem 1: Even or Odd

Write a function:

isEven(number)

Requirements:
- Return true if the number is even.
- Return false if the number is odd.
- Return "Invalid" if the input is not a valid number.

----------------------------------------

Problem 2: Count Vowels

Write a function:

countVowels(str)

Requirements:
- Count the total number of vowels in the string.
- Vowels: a, e, i, o, u (both uppercase and lowercase).
- Return "Invalid" if the input is not a string.

----------------------------------------

Problem 3: Find Largest Number

Write a function:

findLargest(numbers)

Requirements:
- Input must be an array.
- Return the largest number from the array.
- Return "Invalid" if:
  - the input is not an array, or
  - the array is empty.

----------------------------------------

Problem 4: Reverse String

Write a function:

reverseText(text)

Requirements:
- Return the reversed string.
- Return "Invalid" if the input is not a string.

Example:
Input: "hello"
Output: "olleh"

----------------------------------------

Problem 5: Multiplication Table

Write a function:

multiplicationTable(number)

Requirements:
- Return an array containing the multiplication table of the given number from 1 to 10.
- Return "Invalid" if the input is not a valid number.

Example:
Input: 5

Output:
[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
