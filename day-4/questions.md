## 🟢 Problem 1 — Find Missing Number

Write a function `findMissing(numbers)` that returns the missing number from a sequence.

### 📝 Example

```javascript
findMissing([1, 2, 3, 5]);
```

### ✅ Output

```text
4
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not an array.
- ❌ Array is empty.
- ❌ Any element is not a finite number.

## 🟢 Problem 2 — Anagram Checker

Write a function `isAnagram(str1, str2)` that returns `true` if two strings are anagrams.

### Rules

- ✅ Ignore uppercase/lowercase.
- ✅ Ignore spaces.

### 📝 Example

```javascript
isAnagram("Dormitory", "Dirty room");
```

### ✅ Output

```text
true
```

### ⚠️ Return `"Invalid"` if:

- ❌ Any input is not a string.

### ✅ Output

### ⚠️ Return `"Invalid"` if:

## 🔴 Problem 5 — Longest Common Prefix

Write a function `longestCommonPrefix(words)` that returns the longest common prefix among all strings.

### 📝 Example

```javascript
longestCommonPrefix([
    "flower",
    "flow",
    "flight"
]);
```

### ✅ Output

```text
fl
```

### Another Example

```javascript
longestCommonPrefix([
    "dog",
    "racecar",
    "car"
]);
```

### ✅ Output

```text
""
```

### ⚠️ Return `"Invalid"` if:

- ❌ Input is not an array.
- ❌ Array is empty.
- ❌ Any element is not a string.
