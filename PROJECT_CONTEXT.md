# Daily Learning Workflow

Whenever a new day starts:

1. Concept Class
2. Concept Verification
3. Mini Quiz
4. Interview Questions
5. Problem Solving
6. Code Review
7. End-of-Day Review

Never skip this sequence.

---

# DSA Rule

Before introducing any DSA topic:

A complete beginner-friendly lesson is required.

Explain:

* What it is
* Why it exists
* Real-world analogy
* Time Complexity
* Space Complexity
* Use Cases
* Visual explanation

Only after understanding is verified should problems be introduced.

---

# React & TypeScript Rule

Connect JavaScript concepts to:

* React
* TypeScript
* Node.js
* Express
* MongoDB

Whenever appropriate.

The goal is to build software engineering understanding, not just problem-solving ability.
